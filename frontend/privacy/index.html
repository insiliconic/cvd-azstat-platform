Cardiostatistics

Məxfilik siyasəti

Qısaca: şəxsi məlumat toplamırıq.

Cardiostatistics (veb sayt və mobil tətbiq) ictimai statistika göstərən sadə bir vasitədir. İstifadəçi haqqında şəxsi məlumat toplamır, hesab tələb etmir və profil saxlamır.

Şəxsi məlumat toplamırıq

Sayt və app aşağıdakılardan heç birini soruşmur, saxlamır və ya üçüncü tərəfə ötürmür:

  • Hesab və ya qeydiyyat
  • Ad, soyad
  • E-poçt ünvanı
  • Məkan (GPS)
  • Kontakt siyahısı
  • Kamera və ya mikrofon
  • Reklam identifikatoru

Data mənbəyi

Göstərdiyimiz bütün rəqəmlər Azərbaycan Respublikasının Dövlət Statistika Komitəsinin (Azstat) açıq cədvəllərindən götürülür və hər gün yoxlanılıb yenilənir. Bu, istifadəçi fəaliyyətindən toplanan data deyil, ictimai mənbədən oxunan statistikadır.

Dil və tema seçimi

Seçdiyiniz dil (AZ/EN) və görünüş rejimi (açıq/tünd) yalnız öz cihazınızda saxlanılır — veb saytda brauzerin localStorage-ında, mobil tətbiqdə isə AsyncStorage-də. Bu seçim bizə heç vaxt göndərilmir və yalnız sizin həmin cihazınızda qalır.

Hosting

Sayt GitHub Pages-də yerləşir. Hər veb server kimi, hosting provayderi (GitHub) texniki giriş loglarını (məsələn, IP ünvanı, brauzer növü, baxılan səhifə) öz tərəfində qısa müddət saxlaya bilər — bu, Cardiostatistics-in özünün topladığı deyil, hostinqin standart texniki jurnalıdır.

Tibbi xəbərdarlıq

Saytdakı və tətbiqdəki bütün məlumatlar statistik xarakter daşıyır və tibbi məsləhət deyil. Şəxsi sağlamlıq məsələlərində mütləq həkimə müraciət edin.
